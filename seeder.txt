Build an Automated Benchmark Data
Generator for the Capital Ticketing System
You are a senior TypeScript backend engineer. Your task is to implement a production-ready benchmark
data generator for my existing Capital event ticketing system.
Objective
Implement a fully automated benchmark pipeline that generates reproducible benchmark datasets for my
IEEE Access performance evaluation.
The script must automatically:
Create 1,000 benchmark users (configurable)
Generate Ed25519 keypairs for every user
Encrypt and store private keys exactly as the production application does
Create wallets

Call the /validator/validate endpoint
Save all required benchmark data into validation-data.json
The resulting JSON file will later be consumed directly by k6.
